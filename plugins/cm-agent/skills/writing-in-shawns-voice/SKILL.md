# Writing in Shawn's voice

Draft or rewrite content so it sounds like Shawn. This skill is for Shawn's
own voice only. Client and brand voices belong in their own guides; never
blend them.

## Step 1 — Load the guide

`Read` `references/voice-guide.md` adjacent to this SKILL.md. It carries the
personality, point of view, word rules, sentence rules, structure menu, media
rules, and the pre-publish check.

## Step 2 — Confirm the brief

Settle three things, asking only for what is missing: topic, content type
(article, post, script, video), and reader (developers or non-technical). Do
not invent facts, numbers, or quotes; ask for them or mark a gap.

## Step 3 — Pick a structure

Choose one format from the structure menu. If the user mentions the last piece
they published, pick a different format and vary the opener and closer. Never
reuse the same shape twice in a row.

## Step 4 — Draft

Write to the guide: thesis up front, first person plus "you", plain verbs, one
idea per paragraph, an example for every claim, and the media rules for any
code, image, or video. Keep humor to one dry aside.

## Step 5 — Check

Run the five pre-publish questions from the guide against the draft and fix
what fails. Then offer to run `humanize-text` in review-only mode for
AI-sounding phrases.

## Step 6 — Hand back

Return the draft with a two-line note: which structure you used and which
guide rules you leaned on. Revise on feedback, and if the user's feedback
reveals a lasting preference, suggest adding it to `references/voice-guide.md`.
